# AI transparency / Transparence IA

[Français plus bas](#français)

## English

### In short

Novale was built with the help of **Claude**, an AI model by **Anthropic**, used through claude.ai in October 2026. Most of the code and texts were generated by the AI. A human maintainer directed the work, made the decisions and tested the result. **No AI runs while you use Novale.**

### Who did what

| | Human maintainer | AI (Claude) |
|---|---|---|
| Problem and purpose | Identified the problem: too many new ideas, too few finished projects | Proposed the resting-period approach and its rules |
| Product decisions | Chose and validated the cycle, the name, the scope, the KISS principles | Proposed options (stages, 4 essential questions, growing slots, compost, the name Novale) |
| Design | Set the direction: Swiss style, light theme only, single screen, minimal | Produced the visual design and the interface |
| Code | Reviewed the behaviour of each version | Wrote the HTML, CSS and JavaScript, the Obsidian export and the tests |
| Texts | Validated the tone and vocabulary | Wrote the interface texts, the French and English versions and this documentation |
| Quality | Tested the app and requested changes | Ran automated scenario tests and layout checks on simulated screens |

### What has been checked, and what hasn't

- An automated test (`npm test`) replays the full cycle in a simulated browser: adding an idea, early review, review, ripening, growing, harvest, export, import and language switch.
- The layout was checked on simulated phone, tablet and desktop screens.
- The behaviour was reviewed by the maintainer. **The code has not been independently audited line by line.** Testing on real devices is ongoing.

### At runtime

- No AI model is called.
- No network request is made: no server, no analytics, no fonts or scripts from third parties. Third-party code (JSZip) is included in the repository.
- Your ideas stay in your browser.

### Contributions

AI-assisted contributions are welcome if they are declared. Add a trailer to your commit, for example `Assisted-by: Claude (Anthropic)`, and say in the pull request what the AI did and what you checked. See [CONTRIBUTING.md](CONTRIBUTING.md).

### Copyright note

In some jurisdictions, content generated by AI may not be protected by copyright. The MIT licence applies to the extent that such rights exist. Either way, you are free to use, modify and share Novale.

## Français

### En bref

Novale a été conçu avec l'aide de **Claude**, un modèle d'IA d'**Anthropic**, utilisé via claude.ai en octobre 2026. L'essentiel du code et des textes a été généré par l'IA. Un mainteneur humain a dirigé le travail, pris les décisions et testé le résultat. **Aucune IA n'intervient pendant l'utilisation de Novale.**

### Qui a fait quoi

| | Mainteneur humain | IA (Claude) |
|---|---|---|
| Problème et finalité | A identifié le problème : trop d'idées neuves, trop peu de projets terminés | A proposé l'approche de la jachère et ses règles |
| Décisions produit | A choisi et validé le cycle, le nom, le périmètre, les principes KISS | A proposé des options (étapes, 4 questions essentielles, places de culture, compost, le nom Novale) |
| Design | A fixé la direction : style suisse, thème clair uniquement, un seul écran, sobriété | A produit le design visuel et l'interface |
| Code | A vérifié le comportement de chaque version | A écrit le HTML, le CSS et le JavaScript, l'export Obsidian et les tests |
| Textes | A validé le ton et le vocabulaire | A écrit les textes de l'interface, les versions française et anglaise et cette documentation |
| Qualité | A testé l'application et demandé les corrections | A lancé des tests automatisés du parcours et des contrôles de mise en page sur écrans simulés |

### Ce qui a été vérifié, et ce qui ne l'a pas été

- Un test automatisé (`npm test`) rejoue le cycle complet dans un navigateur simulé : semis, relecture avancée, relecture, mûrissement, culture, récolte, export, import et changement de langue.
- La mise en page a été contrôlée sur des écrans simulés de téléphone, de tablette et d'ordinateur.
- Le comportement a été vérifié par le mainteneur. **Le code n'a pas fait l'objet d'un audit indépendant, ligne par ligne.** Les tests sur de vrais appareils sont en cours.

### Pendant l'utilisation

- Aucun modèle d'IA n'est appelé.
- Aucune requête réseau : pas de serveur, pas de statistiques, ni police ni script de tiers. Le code tiers (JSZip) est inclus dans le dépôt.
- Tes idées restent dans ton navigateur.

### Contributions

Les contributions assistées par IA sont bienvenues si elles sont déclarées. Ajoute une ligne à ton commit, par exemple `Assisted-by: Claude (Anthropic)`, et précise dans la pull request ce que l'IA a fait et ce que tu as vérifié. Voir [CONTRIBUTING.md](CONTRIBUTING.md).

### Droit d'auteur

Dans certains pays, un contenu généré par IA peut ne pas être protégé par le droit d'auteur. La licence MIT s'applique dans la mesure où ces droits existent. Dans tous les cas, tu es libre d'utiliser, de modifier et de partager Novale.
